# Contributing

Thanks for helping improve DonutOrders.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Prefer small, focused changes with a clear purpose.
3. Match existing Java style and package layout under `com.donutorders`.
4. Add or update unit tests under `src/test/java` when practical.
5. Open a pull request describing what changed and why.

## Development

- Java 17+
- Build: `mvn -B package`
- Tests: `mvn -B test`
- Plugin entry point: `src/main/resources/plugin.yml`
